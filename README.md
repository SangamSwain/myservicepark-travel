# 🌴 MyServicePark Travel

A minimalist, high-performance travel journal and destination directory for exploring Odisha, India. Built with clean HTML5, CSS3, and JavaScript, hosted directly via **GitHub Pages**.

---

## 📁 Repository Directory Structure

Maintain this exact folder and file structure for proper pathing and navigation:

```text
myservicepark-travel/
├── index.html                  # Main homepage & featured destinations grid
├── style.css                   # Master stylesheet (global styles, layout, components)
├── script.js                   # Universal search, interactive filters, gallery & lightbox
├── README.md                   # Project documentation & contribution guide
├── assets/                     # Media and dynamic assets
│   └── images/                 # Optimized travel photography (.jpg, .webp, .png)
├── destinations/
│   └── index.html              # Filterable directory of all destinations
└── articles/                   # Individual destination guides & journals
    ├── chilika-lake.html
    ├── gopalpur-beach.html
    └── koraput-valley.html
```

🌿 Safe Workflow: Working with Branches (Web Interface)
To ensure the live website remain unaffected during development, never edit the main branch directly. Always create a temporary working branch, make and preview your changes, and then merge them.

## Step 1: Create a Working Branch
  - Go to the repository home page: "https://github.com/SangamSwain/myservicepark-travel At the top-left of the file browser, click the branch dropdown button (currently showing main).
  - Type a descriptive name for your task in the box (e.g., add-daringbadi-article or feature-add-images).
  - Click Create branch: [your-branch-name] from 'main'.
  - Verify: Make sure the dropdown at the top-left now shows your new branch name.

## Step 2: Make & Commit Your Changes
 - Perform your file additions, image uploads, or text edits (detailed in the sections below).
 - Every time you save a file, select Commit directly to the [your-branch-name] branch and click Commit changes.

## Step 3: Preview Changes on GitHub Pages (Optional)
  - Go to Settings (top menu bar) $\rightarrow$ Pages (left sidebar)
  - .Under Build and deployment $\rightarrow$ Branch, change main to your working branch name.
  - Click Save.
  - Wait 1–2 minutes, then refresh your site link to preview and test your updates live

## Step 4: Merge Your Branch into main
  - Navigate back to the Code tab of your repository.
  - Click the green Compare & pull request banner at the top of the page.
  - Review your changes and click Create pull request.
  - Click Merge pull request $\rightarrow$ Confirm merge.
  - Switch the GitHub Pages setting back to main under Settings $\rightarrow$ Pages.
